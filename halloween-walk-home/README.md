# Halloween Walk Home – Art Pack

Spooky-cute 2D sprites, backgrounds, challenge scenes and four small 3D props from the game Halloween Walk Home, which is in development.

## License
CC0 1.0 Universal (public domain). Use it for anything, including commercial work. No credit required.

## Contents
- `atlas/`: sprite atlases (PNG @2x plus JSON frame maps)
- `backgrounds/`: full-screen backgrounds, 780×1688
- `challenges/`: challenge scene composites
- `styleframe/parts/`: SVG source for every sprite
- `batch1/`, `batch2/`, `batch3/`, `batch4/`: contact sheets for each batch (batch1 also has a composite scene, batch3 a sprite preview)
- `batch4/*.glb`: low-poly 3D props (pumpkin, lantern, gravestone, scarecrow)
- `OPEN_KIT_INVENTORY.md`: every file with its size and hash

## Rebuild
Python 3 with Pillow plus headless Chrome. The scripts in `styleframe/` read colours from `styleframe/palette.css`.

Art: made by the crew.
