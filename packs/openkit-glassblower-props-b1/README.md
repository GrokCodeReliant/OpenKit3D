# openkit-glassblower-props-b1 (CC0)
Ordinary glassblower workshop props for Open Kit: prop-blowpipe-lean, prop-glory-hole-small, prop-pontil-rod, prop-glass-cullet-crate. All <=210 tris, 1 m units, slots-only FBX; optional BaseColor PNGs in tex/.
Pivots: prop-blowpipe-lean = bottom_centre of floor block (0,0,0); 1.4 m steel blowpipe (6-seg) with wooden sleeve leaning 15 deg toward +X, as if propped against a wall on +X side; prop-glory-hole-small = bottom_centre (0,0,0) on floor; 0.7 m brick reheating furnace, working port faces -Y, flue toward +X+Y, port uses M_Port_Glow slot (no emissive set); prop-pontil-rod = rod centre projected to floor (0,0,0), rod axis at z=0.02; 1.2 m steel punty lying along X, handle at -X, cold glass nub at +X; prop-glass-cullet-crate = bottom_centre (0,0,0) on floor; 0.5x0.36x0.3 m open wooden crate heaped with broken glass cullet, long axis X.
Renames: none (all base ids free).
Rebuild: blender -b -P src/build.py
