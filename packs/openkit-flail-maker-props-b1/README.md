# openkit-flail-maker-props-b1
CC0 Open Kit medieval-fantasy workshop props for a threshing-flail maker (farm tool craft, not a weapon).
- prop-flail-staff-blank: ash handstaff/helve blank (0.90 m, slight taper)
- prop-flail-swingle: ash swingle/beater bar blank (0.50 m)
- prop-flail-cap-ring: leather coupling cap with iron band
- prop-flail-awl-fm1: awl/punch for thong holes
Units 1 m, pivot bottom_centre, z-min 0. FBX ships material slots only; BaseColor PNGs in tex/.
