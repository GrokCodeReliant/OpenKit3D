# OpenKit graveyard-b1
Four low-poly graveyard props, PG/tasteful (no gore). 1 m units, bottom-centre pivots, material slots only (no textures).
- prop-headstone-simple: rounded slab + plinth (M_Stone, M_StoneDark)
- prop-headstone-cross: stepped base + stone cross (M_Stone, M_StoneDark)
- prop-coffin-wood: closed wooden coffin, iron handles (M_Wood, M_WoodDark, M_Iron)
- prop-grave-mound: low earth mound (M_Earth) + optional child `prop-grave-mound_marker` wood stub (M_Wood); disable the child to hide it.
