# openkit-hatchet-extras-b1
Open Kit carpenter hatchet extras (CC0-1.0): head blank, eye, handle, wedge. Medieval-fantasy, game-ready.
- Units: metres; pivot bottom-centre (0,0,0), z-min 0, centred x/y.
- fbx/: one FBX per asset (material slots only, no embedded textures).
- tex/: BaseColor PNGs (mat_steel, mat_wood).
