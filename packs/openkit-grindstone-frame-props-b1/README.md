# openkit-grindstone-frame-props-b1

CC0 Open Kit medieval-fantasy grindstone **frame** workshop props: wooden A-frame stand, axle rod, shallow water trough, crank handle. No wheel included (pairs with any grindstone wheel).

- Units: 1 m. Pivot: bottom centre (0,0,0), z-min 0, x/y centred.
- `fbx/` material slots only, no embedded textures. `tex/` flat BaseColor PNGs (64x64) per material.
- See MANIFEST.json for tris/dims.
