# Open Kit: Medieval Furniture Extras, Batch 1

Low-poly tavern/shop furniture for games. **CC0 1.0** — use commercially; credit optional.

Ship shape: **FBX + PNG only** (no Unity materials, prefabs, or .meta).

| Asset | Notes |
|---|---|
| prop-table-round | Round wood table |
| prop-stool-tall | Tall stool |
| prop-shelf-wall | Wall shelf |
| prop-coffer-wood | Wooden coffer (faceted lid) |
| prop-counter-tavern | Tavern counter |

Scale: 1 unit = 1 m. Very low-poly / blocky by design. On merge with other packs, pick one shared wood/iron texture set (this pack used a different procedural seed than medieval-env-b1).
