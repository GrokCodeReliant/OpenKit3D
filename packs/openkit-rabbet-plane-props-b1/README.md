# openkit-rabbet-plane-props-b1
CC0 Open Kit medieval-fantasy rabbet (rebate) plane blanks: body, iron, wedge, fence. 1 m units, pivot bottom-centre, made procedurally in Blender 5.2.1. FBX carries material slots only; BaseColor PNGs in tex/.

Assets (fbx/): prop-rabbet-plane-body-rb1, prop-rabbet-plane-iron-rb1, prop-rabbet-plane-wedge-rb1, prop-rabbet-plane-fence-rb1. See MANIFEST.json for dimensions and tri counts.
