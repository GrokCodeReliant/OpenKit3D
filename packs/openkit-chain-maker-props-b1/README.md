# openkit-chain-maker-props-b1

Open Kit CC0 medieval-fantasy chain-maker workshop props (4 low-poly assets, metres, bottom-centre pivots).

- fbx/ - game-ready FBX (material slots only, no embedded textures)
- tex/ - flat BaseColor PNGs (OK_IronDark, OK_IronBright)
- CONTACT_SHEET.png - preview
- MANIFEST.json - per-asset tris, dimensions, materials, descriptions
