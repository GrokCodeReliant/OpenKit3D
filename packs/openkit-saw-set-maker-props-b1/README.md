# openkit-saw-set-maker-props-b1

Open Kit medieval-fantasy saw-set workshop props (CC0-1.0). Four low-poly props: saw-set pliers, setting anvil block, set gauge plate, tooth-file blank. No saw blades.

- Units: 1 m. Pivot: bottom centre (0,0,0), z-min 0, centred x/y.
- fbx/: FBX, material slots only, no embedded textures.
- tex/: flat BaseColor PNGs per material (ok_steel, ok_iron_dark, ok_wood_handle).
- CONTACT_SHEET.png: preview renders.
