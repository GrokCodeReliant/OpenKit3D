Made with Blender 5.2.1, Python and bmesh. No third-party models, textures, downloaded assets, trademarks or named IP. No image generation.

The build script reuses geometry, collision and export helpers from the kit's Training Yard build script (CC0), adding a floor-top pivot option and a chamfered-box helper. Dimensions and grid conventions match the kit's stone wall and floor modules (also CC0 kit work). Preview images were rendered from the exported FBX files in Blender Workbench.
