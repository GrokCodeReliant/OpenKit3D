# openkit-camp-props-b1 (Open Kit)
Camp props: prop-tent-wedge, prop-bedroll-cp1, prop-camp-stool, prop-cookpot-hang.
Slots-only FBX (no image/video nodes, no texture paths); 1 unit = 1 m; bottom_centre pivots (y=0 ground). Shared PBR maps in tex/ (byte copies from openkit-barrel-chest-b1). See MANIFEST.json for slot→texture mapping, tris, sizes, SHA-256.
Rename: prop-bedroll → prop-bedroll-cp1 (name exists in openkit-dnd). prop-cookpot-hang is a tripod+hanging pot over a flat cold-ash patch; no fire ring, stones or flames — distinct from light-hearth campfire-ring-iron / outdoor campfire and openkit-dnd prop-cookpot.
