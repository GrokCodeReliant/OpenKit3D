# openkit-rushlight-maker-props-b1
4 rushlight-maker workshop props (procedural Blender bpy scripts). 1 m units, Z-up in Blender / Y-up FBX, slots-only materials; flat BaseColor tex in `tex/`.
## Pivots (all bottom_centre, z=0 on floor)
- prop-rush-bundle — lying bundle of peeled rushes along X, centred.
- prop-grease-pan — centre of pan bowl bottom; handle points +X.
- prop-rush-dip-frame — centre of A-trestle footprint; ridge along X.
- prop-rushlight-holder-blank — centre of wooden base block.
