# openkit-mining-props-b1 (CC0)
Ordinary mining props for Open Kit. Assets: prop-ore-crate-mn1, prop-pickaxe-lean, prop-lantern-mine. All <=210 tris, 1 m units, Y-up FBX with material slots only; optional BaseColor PNGs in tex/ (assign in engine).
Pivots: ore-crate = bottom centre under skids (long axis X); pickaxe-lean = handle butt on floor, leans 15 deg toward +Y (wall side), head along X; lantern-mine = bottom centre of base plate. See MANIFEST.json.
