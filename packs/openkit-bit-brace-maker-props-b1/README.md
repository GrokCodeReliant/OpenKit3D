# openkit-bit-brace-maker-props-b1
CC0 Open Kit medieval-fantasy bit-brace (hand-brace) workshop props: brace frame blank, breast pad blank, chuck blank, spoon bit blank.

- fbx/: 4 FBX, material slots only (mat_wood_oak, mat_iron_dark), no embedded textures
- tex/: flat BaseColor PNGs per material
- Units 1 m, pivot bottom-centre at origin, z-min 0.
See MANIFEST.json for tris/dims.
