# openkit-stringmaker-props-b1

4 medieval-fantasy gut-string maker workshop props (CC0, procedural Blender bpy, 1 m units, slots-only FBX). Raw string stock and blanks only; no finished bows or weapons.

- `prop-gut-string-hank` — 152 tris — bottom_centre (0,0,0); laid coil hank of dried gut string stock, linen tie across + knot; raw stock, not a strung bow; distinct from rope-maker coils
- `prop-bridge-blank-sg1` — 60 tris — bottom_centre (0,0,0); unfinished maple bridge blank, stepped rough-sawn profile, pencil layout line + foot marks; no string notches cut
- `prop-winding-peg-blank` — 52 tris — bottom_centre (0,0,0); laid boxwood winding peg blank: tapered shaft + flat paddle head, string hole only marked; distinct from peg-maker tent/joinery pegs
- `prop-resin-cake-tray` — 172 tris — bottom_centre (0,0,0); ash tray of 5 poured rosin cakes (amber/dark) + broken shard; string-dressing rosin, not candle wax
