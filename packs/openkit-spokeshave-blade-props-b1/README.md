# openkit-spokeshave-blade-props-b1

CC0 Open Kit medieval-fantasy workshop blanks for building a spokeshave: iron, sole, wedge, handle. Separate parts, not the assembled tool.

- Units: 1 m. Pivot bottom-centre (0,0,0), z-min 0, centred in X/Y.
- `fbx/` 4 FBX (material slots only, no embedded textures). `tex/` flat BaseColor PNGs.
- Materials: steel_blade, wood_beech, wood_walnut.
