# openkit-rope-splicer-props-b1
CC0 Open Kit medieval-fantasy rope-splicing tools: splicing fid, marlinespike, serving mallet, whipped rope end blank.

- fbx/: game-ready meshes, material slots only (no embedded textures)
- tex/: flat BaseColor PNGs per material (oak, iron, hemp, tarred_twine)
- CONTACT_SHEET.png: preview

Units 1 m, pivot bottom centre at origin. See MANIFEST.json.
