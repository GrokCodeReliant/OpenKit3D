# openkit-lute-maker-props-b1

Four low-poly props for a lute maker's bench, covering bowl-back lute body construction. This pack does not cover string making, furniture, or finished instruments.

| Asset | Tris | Dims m (XYZ) | Description |
|---|---|---|---|
| prop-lute-rib-blank | 104 | 0.622 x 0.116 x 0.078 | pair of thin bent maple/yew lute-bowl ribs, tapered at both ends and arched lengthwise, ready to glue onto the mold |
| prop-pegbox-blank | 64 | 0.241 x 0.064 x 0.05 | unfinished tapered lute pegbox blank: two cheeks on a back plate with an end block and started peg holes marked along both sides |
| prop-soundboard-blank | 100 | 0.34 x 0.312 x 0.006 | thin pear-shaped spruce lute soundboard plate with the circular rose cut and one harmonic bar glued across |
| prop-lute-mold | 92 | 0.56 x 0.4 x 0.16 | solid wooden half-pear lute bowl mold on a base board, the form over which ribs are bent and glued |

- 1 m units. Pivot is bottom_centre (0,0,0). Bench parts lie flat, and the mold stands on its base board.
- FBX files carry material slots only (path_mode STRIP), with no embedded textures. Simple BaseColor PNGs are in `tex/`.
