# openkit-button-mold-maker-props-b1
CC0 Open Kit medieval-fantasy button mold maker props (casting molds for pewter buttons).
- prop-button-mold-half — stone mold half, 6 button cavities + pour channel
- prop-pewter-button-blank — unfinished pewter disc with shank stub
- prop-button-shank-wire — bent brass shank wire blanks
- prop-mold-clamp-bm1 — wooden C-frame screw clamp / mold press
Units metres, pivot bottom-centre, z-min 0. FBX uses material slots only; BaseColor PNGs in tex/.
