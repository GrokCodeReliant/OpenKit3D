# openkit-try-square-maker-props-b1
CC0 Open Kit medieval-fantasy try-square (carpenter's square) workshop props: stock blank, blade blank, rivet set, check block.
- fbx/: 4 FBX (material slots only, no embedded textures)
- tex/: flat BaseColor PNGs per material
- Units 1 m, pivot bottom-centre (0,0,0), Z-up.
