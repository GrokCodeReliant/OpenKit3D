# openkit-basket-mender-props-b1
Four CC0 low-poly medieval-fantasy basket-mending props: willow patch strip, rim withy, stake peg, mending knife.
- fbx/: game-ready FBX (1 m units, bottom-centre pivot, material slots only)
- tex/: flat BaseColor PNGs per material
See MANIFEST.json for tris, dimensions and descriptions.
