# openkit-icons-inventory-b1
16 flat fantasy inventory/weapon glyphs, 256×256 transparent PNG, CC0-1.0. Regenerate: `python3 src/gen_icons.py` (Pillow, deterministic, 4× supersampled, consistent 6px-at-4× outline, auto-centred).
Files: `icons/icon-*.png`, `sheet/CONTACT_SHEET.png` (4×4 preview), `MANIFEST.json` (names, categories, sha256).
Original generic designs; not derived from B01 game icons. Naming is kebab `icon-*` only.
