# openkit-drawknife-extras-b1
CC0 Open Kit medieval-fantasy drawknife workshop extras: blade blank, handle blank, ferrule ring, tang pin. Companion parts, not a remake of prop-drawknife-pg1.
- Units 1 m, pivot bottom_centre (0,0,0), z-min 0, centred x/y.
- fbx/: FBX (material slots only, no embedded textures). tex/: BaseColor PNGs (T_Steel, T_Ash, T_Brass) to hook up in engine.
