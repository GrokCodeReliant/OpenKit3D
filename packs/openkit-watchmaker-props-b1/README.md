# openkit-watchmaker-props-b1
CC0 Open Kit medieval-fantasy watchmaker (pocket-watch / small-clock) workshop blanks: watch case shell, balance wheel, mainspring barrel, winding key.

- Units 1 m, pivot bottom-centre (0,0,0), z-min 0.
- fbx/: FBX (path_mode STRIP, material slots only, no embedded textures).
- tex/: flat BaseColor PNGs shipped separately.
